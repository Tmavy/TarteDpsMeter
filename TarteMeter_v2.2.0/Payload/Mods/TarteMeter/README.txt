TarteMeter v2.2.0

F6  Save the current encounter to LOGS and reset combat data
F9  Reopen the meter window
F10 Toggle click-through mode

Use the gear button for opacity, click-through, always-on-top, and text size.
The LOGS tab contains saved encounters, event rows, and timelines.

RESET never clears an encounter unless its history entry was saved successfully.
The meter counts total outgoing damage across all enemies and attributes it to
party characters using conservative LastAttacker/source/active-character logic.
