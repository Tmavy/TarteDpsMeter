TarteMeter v3.0.1 - Compact Stable Edition
=============================================

TITLE BAR
---------
- Replaced text-based -, [] and X controls with Windows vector glyphs.
- Increased the minimize, maximize/restore and close hit areas to 34 x 32 px.
- Maximize now changes to the Restore glyph while the window is maximized.
- Settings and Settings-close controls use the same aligned icon system.
- The title bar height is fixed at 32 px and no longer grows with meter text scale.
- COMPACT and version labels hide at narrow widths before they can overlap the controls.
- Fixed the stale visible v2.7.8 badge; every visible/runtime/installer version is now 3.0.1.

COMPACT INTERFACE
-----------------
- Preserved the two-line character rows from v2.7.9.
- Preserved the combined History + selected encounter breakdown view.
- Preserved proportional 0-100 damage-share fill bars.
- Preserved explicit dark templates for buttons, tabs and ComboBoxes.
- No frozen Character column and no separate Logs tab.

COMBAT AND ATTRIBUTION
----------------------
- No combat logic was rewritten for v3.0.1.
- main.lua is byte-equivalent to the validated v2.7.5 core after version normalization.
- Exactly two verified hooks remain.
- Context-first source attribution, exact source-target priority, Chako identity,
  Chako post-swap probing and active-character fallback ordering are preserved.
- Idle time and enemy/boss actor changes cannot reset totals.
- F6 remains transactional and aborts Reset if the encounter cannot be saved.

SAFETY / OPTIMIZATION
---------------------
- Damage queue: 16,384 maximum; batch: 384.
- Source records: 512 maximum.
- Monster snapshot: one conditional scan per relevant batch, capped at 1,024 actors.
- Recent target attribution: 64 entries.
- Pending Timeline rows: 4,096 maximum.
- In-memory preview: 2,000 events; JSON sample: 500 events.
- No UObject is retained in deferred combat queues.
- All overlay timers, hotkeys and mutex resources are released on shutdown.

INSTALLER HOTFIX
----------------
- Fixed Windows Script Host error 800A03EA in TarteMeter Setup.vbs.
- Removed VBScript line-continuation syntax from both launcher scripts.
- Normalized launcher files to strict ASCII with one CRLF line ending per line.
- Fixed the same malformed line endings in the installed LaunchOverlay.vbs fallback.
- Added release validation for CRCRLF, UTF-8 BOM, continuation-line gaps and quote balance.
