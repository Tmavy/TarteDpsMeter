TARTEMETER PATCH NOTES — v2.5.5 TO v2.6.0

v2.5.5 — Dana summon ownership experiment
- Added a bounded persistent summon-owner experiment for Dana.
- Kept generic swap carry-over disabled.
- Added summon ownership diagnostics.
- This approach was later removed because the available data did not justify a
  generic persistent-owner rule.

v2.5.6 — Targeted fallback and stability audit
- Removed the v2.5.5 persistent-owner experiment.
- Tested event-driven enemy HP fallback attribution for Dana's summon.
- Excluded the suspected allied summon from enemy matching.
- Added hook callback guards and a monster-refresh cooldown.
- Removed the installer's automatic overlay-test checkbox.
- Expanded theme resource coverage.
- The HP fallback did not activate reliably and was removed later.

v2.5.7 Diagnostic — Controlled ownership capture
- Restored the conservative v2.5.4 attribution baseline.
- Removed speculative Dana ownership and HP fallback logic.
- Logged raw LastAttacker class, object name, and bounded owner chains.
- Identified the summon attacker as DsMon_Chaco_V2_C with DsMCTR_C ownership.
- Added bounded diagnostics, callback guards, and scan cooldowns.

v2.5.8 — Exact summon rule and settings repair
- Added exact DsMon_Chaco_V2_C summon detection.
- Added a new overlay mutex and runtime build marker to prevent an older hidden
  overlay process from serving the updated installation.
- Fixed the PowerShell settings writer that could save only the Opacity line.
- Moved settings to window_settings_v6.ini with legacy migration.
- Added explicit theme Apply behavior and synchronous settings persistence.

v2.5.9 — Separate summon row
- Added Dana-Golem as a separate damage row.
- Matched the exact summon class before generic owner and active-character
  fallback paths.
- Added a short target-specific grace for transient nil LastAttacker values.
- Added separate Dana and summon colors.

v2.6.0 — Native crash fix and Chako
- Renamed Dana-Golem to Chako.
- Rebuilt the combat lifetime architecture to prevent stale Unreal actor pointers.
- Removed persistent controller, monster, position-actor, and pending-target
  UObject references.
- Damage hooks now capture plain Lua data only.
- Delayed target and LastAttacker resolution reacquires fresh objects on the game
  thread via ExecuteInGameThread.
- LoopAsync is restricted to plain Lua data and file I/O.
- Added a combat-generation guard so delayed hits cannot cross RESET.
- Chako is excluded from enemy-target selection and remains a separate row.
- Preserved the conservative damage-attribution order, raid auto-save, history,
  exports, UI settings, themes, hotkeys, and adjustable LOGS timeline.
