TARTEMETER v2.7.4 - START HERE

INSTALL
1. Extract the entire archive.
2. Run: TarteMeter Setup.vbs
3. Confirm or browse to the DragonSword game folder.
4. Press INSTALL / UPDATE.

The setup installs TarteMeter and adds UE4SS only when a working UE4SS
installation is not already present.

DEFAULT HOTKEYS
F6  Reset and archive the current encounter
F9  Show / hide TarteMeter
F10 Toggle click-through

IMPORTANT
- Keep all installer files together.
- Do not run Setup.ps1 directly unless troubleshooting.
- Chako is displayed as an independent damage source.
- Existing history, themes, key bindings and window settings are preserved.
- Text size can be adjusted from 60% to 220%.
- At narrow widths, secondary columns collapse before character names.

UNINSTALL
Run TarteMeter Setup.vbs again and open the Uninstall tab.
UE4SS removal remains an explicit optional choice.


IMPORTANT v2.7.4 BEHAVIOR
Damage remains cumulative through idle periods, summons, boss phases, and character switches. Use RESET when you intentionally want to start a new meter.


IMPORTANT v2.7.4 BEHAVIOR
- Chako auto-attacks and Dana-commanded Chako skills are both intended to use the separate CHAKO row.
- The title-bar X exits TarteMeter completely. Use F9 when you only want to hide it.
- TarteMeter automatically exits when the DragonSword process that launched it closes.
