TarteMeter v3.1.3 - Compact AoE Source Ownership

Compact detached WPF damage meter for DragonSword: Awakening.

v3.1.3 fixes multi-target residual AoE ownership after character switching. A verified projectile/source or target.LastAttacker can propagate ownership only to nearby same-value callbacks in the same 180 ms burst. The active character cannot seed this cache.

Hotkeys and UI behavior remain configurable in the overlay settings.
